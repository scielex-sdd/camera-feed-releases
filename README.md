## Download

- **[Camera Feed for Windows](https://github.com/scielex-sdd/camera-feed-releases/releases/latest/download/ScielexCameraFeed-win-Setup.exe)**:
  run the installer. Once installed, the app updates itself.
- **[Data import utility](https://github.com/scielex-sdd/camera-feed-releases/releases/latest/download/ScielexCameraFeed-DataImport.exe)**:
  only if you are moving from the old Camera System app. Run it on the PC that ran the old app to bring its
  pens, groups and routines across.

If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

All versions: [Releases](https://github.com/scielex-sdd/camera-feed-releases/releases).
